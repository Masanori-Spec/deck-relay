使い方 / Guide

選択してから変更 / Select before changing

PPTX を開き、元のスライド・現在の行き先・テキストで絞り込みます。変更するクリック動作にチェックを入れ、新しい行き先を選択して、全選択のプレビューを確認してください。フィルター外の選択も一覧に残ります。

Open a PPTX and filter by source, current destination or text. Check the specific click actions, choose a new destination and review every selection. Selections outside the current filter remain in the preview.

共有関係の扱い / Shared relationships

同じ内部関係を複数のボタンやホバーが共有することがあります。DeckRelay は古い関係の行き先を書き換えず、選択したクリック参照だけを新しい関係へ付け替えます。

Several buttons or hover actions may share one relationship. DeckRelay keeps the original relationship target and changes only each selected click reference.

保存する 3 ファイル / Three files to keep

編集可能な PPTX、入力と出力のハッシュを含む検証記録 JSON、元ファイルに結びついた変更計画 JSON を保存できます。計画の再読み込みには同じ入力 SHA-256 が必要です。画面では 1 バッチに 1 つの新しい行き先を指定します。

Save the editable PPTX, verification receipt JSON and input-bound replay plan JSON. Replaying a plan requires the same original SHA-256. The interface uses one new destination per batch.

対象と対象外 / Scope

同じデッキ内の指定スライドに移動する、図形または明示的なテキスト区間のクリック動作だけが対象です。相対移動、ホバー、外部リンク、カスタムショー、Zoom、マスター・レイアウト内の動作、グループ全体の動作は変更しません。対象外を計画で選ぶと処理を拒否します。

Only explicit named-slide click actions on supported shapes or text runs are editable. Relative navigation, hover, external links, custom shows, Zoom, master/layout actions and group-wide actions are preserved. Unsupported plan selections block the edit.

制限とプライバシー / Limits & privacy

署名・マクロ・暗号化のない PPTX、入出力 25 MiB、展開合計 100 MiB、300 スライド・3,000 動作まで。XML は 1 パーツ 4 MiB、解析合計 16 MiB・200,000 要素までです。計画 JSON は 1 MiB までで、不正な UTF-8 を拒否します。属性・名前空間にも個別の上限があります。外部リンクは開かず、ファイルを送信・自動保存しません。ページを閉じると読み込みデータは消えます。

Unsigned, macro-free, unencrypted PPTX only. Input/output 25 MiB, expanded total 100 MiB, 300 slides and 3,000 actions. Inspected XML is limited to 4 MiB per part and 16 MiB / 200,000 nodes overall. Replay plans are limited to 1 MiB with malformed UTF-8 rejected; separate attribute and namespace-work caps also apply. No external links are opened and files are not uploaded or automatically saved. Closing the page discards imported data.

検証の意味 / What verification means

元ファイルの順番、未選択の動作、未変更パーツのバイト列とメディアのハッシュを確認します。合成デモでは独立した Python 検証と LibreOffice の 8 枚の描画一致を確認済みです。特定の実装コミットでは、サンドボックス有効の Chromium で 12 シナリオが成功し、実際のダウンロード、オフライン処理、再読み込み、中断・リセットを確認しました。デスクトップ・モバイル幅と 1 ページの印刷プレビューも確認済みです。PowerPoint 本体でのスライドショー動作、すべての見た目、正式なアクセシビリティ適合を保証しません。

Checks cover slide order, unselected actions, unchanged part bytes and media hashes. The synthetic demo passed independent Python verification and eight identical LibreOffice before/after renders. At the pinned implementation commit, sandbox-enabled Chromium passed 12 scenarios covering actual downloads, offline processing, reimport, interruption and reset. Desktop/mobile widths and the one-page print preview were inspected. This does not certify native PowerPoint slideshow behavior, universal visual fidelity or formal accessibility conformance.

検証対象 / Evidence: run 37180574361 · commit 2ad560fe0c8cdbfdca6c203cd94cc115fca55793。実機のスマートフォン・プリンター、他のブラウザや実際の顧客デッキは未検証です。

Evidence is pinned to that run and commit. Native PowerPoint, other engines, real mobile hardware/printers and a real-world deck corpus remain unverified. Later documentation revisions require their own exact-head audit.
